# Support

## Where to get help

- **Bug reports and reproducible defects:** GitHub Issues using the bug report form.
- **Feature proposals:** GitHub Issues using the feature request form.
- **Security problems:** see `SECURITY.md` and report privately through GitHub Security
  Advisories, never a public issue.
- **Discord account, billing, or API problems:** use Discord's own support channels when the
  problem is on the Discord side.

## Before asking

1. Check the README troubleshooting section.
2. Search existing issues.
3. Reproduce on the latest release with a clean `.env.local` and a dedicated bot token.

## What support covers

This is a free, maintainer-run project. Support covers defects in the latest release and
questions about documented behavior. It does not cover customized deployments, third-party MCP
clients, or consulting work.

Never include bot tokens, webhook tokens, invite codes, backup payloads, or private guild data in
a support request.

## Response expectations

Best effort, usually within a week. Issues without version information or a reproduction may be
closed with a request for details.
